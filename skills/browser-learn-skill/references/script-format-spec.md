# 录制脚本格式规范

本文档定义 AI Agent 可理解的录制脚本格式，包括必需字段、可选字段、歧义标注和异常处理规范。

---

## 1. 格式概述

### 1.1 设计原则

1. **简洁性**：只保留 AI 执行所需的必要信息
2. **可扩展性**：支持添加元数据和注释
3. **标准化**：统一字段命名和类型定义
4. **可验证性**：每步操作都应有明确的预期结果

### 1.2 文件格式

- **输入格式**：JSON（原始录制事件流）
- **输出格式**：JSON（清洗后、解读后）
- **压缩格式**：支持 `.json.gz` 压缩存储

## 2. 事件类型定义

### 2.1 支持的事件类型

| 事件类型 | 代码 | 描述 | 必需参数 |
|---------|------|------|---------|
| **点击** | `click` | 鼠标点击事件 | selector, element_info |
| **双击** | `dblclick` | 鼠标双击事件 | selector, element_info |
| **输入** | `type` | 文本输入事件 | selector, value |
| **清空** | `clear` | 清空输入框 | selector |
| **悬停** | `hover` | 鼠标悬停事件 | selector |
| **选择** | `select` | 下拉选项选择 | selector, option_value |
| **勾选** | `check` | 复选框勾选 | selector, checked |
| **提交** | `submit` | 表单提交 | selector |
| **导航** | `navigate` | 页面导航 | url |
| **等待** | `wait` | 等待条件达成 | condition, timeout |
| **滚动** | `scroll` | 页面滚动 | direction, amount |
| **截图** | `screenshot` | 页面截图 | filename |
| **执行JS** | `execute` | 执行JavaScript | script |
| **切换框架** | `switch_frame` | 切换iframe | frame_selector |
| **切换标签** | `switch_tab` | 切换浏览器标签 | tab_index |
| **等待加载** | `wait_load` | 等待页面加载 | timeout |

## 3. 必需字段与可选字段

### 3.1 必需字段（Required）

| 字段路径 | 类型 | 描述 | 示例 |
|---------|------|------|------|
| `event_id` | string | 事件唯一标识符 | `"evt_001"` |
| `type` | string | 事件类型 | `"click"` |
| `timestamp` | string | ISO-8601 时间戳 | `"2026-04-29T10:30:00.123Z"` |
| `sequence` | integer | 执行顺序号 | `1` |
| `data.selector` | string | 元素选择器 | `"#login-btn"` |

### 3.2 可选字段（Optional）

| 字段路径 | 类型 | 描述 | 默认值 |
|---------|------|------|-------|
| `data.value` | string | 输入值 | `null` |
| `data.option_value` | string | 下拉选项值 | `null` |
| `data.condition` | string | 等待条件 | `null` |
| `data.timeout` | integer | 超时时间(毫秒) | `30000` |
| `data.direction` | string | 滚动方向 | `"down"` |
| `data.amount` | integer | 滚动量 | `300` |
| `element_info.tag` | string | HTML标签名 | - |
| `element_info.text` | string | 元素文本 | - |
| `element_info.is_visible` | boolean | 可见性 | `true` |
| `element_info.is_enabled` | boolean | 可用性 | `true` |
| `context.url` | string | 当前页面URL | - |
| `context.title` | string | 页面标题 | - |

### 3.3 AI生成字段（Generated by AI）

| 字段路径 | 类型 | 描述 | 生成时机 |
|---------|------|------|---------|
| `semantic_meaning` | string | 操作的语义含义 | 解读阶段 |
| `ambiguity_flags` | array | 歧义标记列表 | 解读阶段 |
| `confidence` | float | 操作置信度(0-1) | 解读阶段 |
| `expected_result` | string | 预期结果描述 | 解读阶段 |
| `warnings` | array | 警告信息 | 解读阶段 |
| `requires_confirmation` | boolean | 是否需要确认 | 解读阶段 |

## 4. 歧义标注规范

### 4.1 歧义类型

| 歧义类型 | 代码 | 描述 | 标记字段 |
|---------|------|------|---------|
| **选择器歧义** | `selector_ambiguous` | 多个元素匹配同一选择器 | `selector_matches` |
| **文本歧义** | `text_ambiguous` | 按钮文本模糊 | `alternatives` |
| **位置歧义** | `position_ambiguous` | 元素位置不确定 | `possible_positions` |
| **意图歧义** | `intent_ambiguous` | 操作目的不明确 | `possible_intents` |
| **语义歧义** | `semantic_ambiguous` | 内部术语无法理解 | `term_explanation` |

## 5. 异常标注规范

### 5.1 异常类型

| 异常类型 | 代码 | 描述 | 严重程度 |
|---------|------|------|---------|
| **不稳定选择器** | `selector_unstable` | 包含动态ID或随机值 | ⚠️ 中 |
| **元素缺失** | `element_missing` | 执行时元素可能不存在 | 🔴 高 |
| **副作用** | `side_effect` | 操作产生额外副作用 | 🔴 高 |
| **时间依赖** | `timing_critical` | 操作依赖精确时序 | ⚠️ 中 |
| **数据依赖** | `data_dependent` | 依赖外部数据状态 | ⚠️ 中 |
| **权限不足** | `permission_denied` | 可能无操作权限 | 🔴 高 |

### 5.2 异常对象结构

```json
{
  "exception": {
```

## 6. 清洗规则

### 6.1 去除内容（必须移除）

| 内容类型 | 描述 | 规则 |
|---------|------|------|
| **鼠标移动轨迹** | mousemove 事件 | 连续 mousemove 只保留首尾 |
| **冗余等待** | 手动添加的无意义等待 | 移除 < 100ms 的等待 |
| **重复事件** | 相同操作重复录制 | 合并去重 |
| **滚动微调** | 微小的滚动调整 | 移除 < 50px 的滚动 |
| **无效悬停** | 无操作的悬停 | 移除无副作用的 hover |
| **调试信息** | console.log 等调试代码 | 移除页面内调试操作 |

### 6.2 合并规则

| 场景 | 合并方式 |
|------|---------|
| 连续点击同一元素 | 合并为单次点击 |
| 连续输入到同一字段 | 合并为单次输入 |
| 连续等待同一条件 | 合并为一次等待 |
| 快速连续操作 (< 100ms) | 根据上下文判断合并 |

### 6.3 优化规则

| 规则 | 优化方式 |
|------|---------|
| **XPath 转 CSS** | 转换为更简洁的 CSS 选择器 |
| **绝对坐标转选择器** | 使用元素选择器替代坐标 |
| **长文本截断** | 超长文本保留前100字符 |
| **URL 简化** | 只保留关键路径 |
