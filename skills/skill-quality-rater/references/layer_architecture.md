# L1/L2/L3 分层架构说明

> **原文核心创新**：Skill内容的分层设计原则

---

## 核心概念

Skill内容分为三个层级，每个层级有不同的职责和位置：

```
┌─────────────────────────────────────────────────────────┐
│  L1 层：原则指导（WHY）                                   │
│  位置：SKILL.md 顶部                                      │
│  内容：告诉 AI "为什么这样做"                             │
├─────────────────────────────────────────────────────────┤
│  L2 层：操作指引（HOW）                                    │
│  位置：SKILL.md 正文                                      │
│  内容：告诉 AI "具体怎么做"                               │
├─────────────────────────────────────────────────────────┤
│  L3 层：参考细节（WHAT）                                   │
│  位置：references/ 目录                                   │
│  内容：告诉 AI "具体参数/格式是什么"                      │
│  特点：零 token 成本（按需读取）                           │
└─────────────────────────────────────────────────────────┘
```

---

## 各层职责

| 层级 | 位置 | 内容 | Token成本 |
|:---:|:---|:---|:---:|
| L1 原则 | SKILL.md顶部 | 决策指导(WHY) | 必读 |
| L2 操作 | SKILL.md正文 | 步骤流程(HOW) | 必读 |
| L3 参考 | references/ | 详细规格(WHAT) | 按需 |

---

## 常见层错位

### ❌ L3参考细节塞进SKILL.md

**问题**：参数列表、模板写进正文

**正确**：放到 references/

### ❌ L1/L2塞进references/

**问题**：原则步骤放在参考资料目录

**正确**：L1/L2必须在SKILL.md

### ❌ scripts当资料读

**问题**：写"读取scripts/template.py的内容"

**正确**：模板放references/，脚本用于执行
